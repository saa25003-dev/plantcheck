Firebase & GitHub Pages / Hosting 公開ガイド

このアプリの特徴

このWebアプリは単一のHTMLファイルで完結しており、Firebase Firestoreを使ってリアルタイムにデータベースと連携します。GitHub PagesやFirebase Hosting、Vercel等でそのまま公開可能です。

🚀 1. GitHub Pages で公開する方法

  1. GitHubで新しいリポジトリ（例: crop-tracker）を作成。
  2. このコードを index.html という名前で保存してプッシュ。
  3. リポジトリの Settings > Pages を開く。
  4. Sourceを Deploy from a branch にし、main (または master) / root を選択して保存。
  5. 数分後に発行されるURLからアクセスできます。

🔥 2. Firebase Hosting で公開する方法

  1. ターミナルで npm install -g firebase-tools を実行。
  2. firebase login でログイン。
  3. firebase init hosting を実行し、プロジェクトを選択。
  4. 公開フォルダ（Public dir）にこの index.html を配置。
  5. firebase deploy を実行すれば公開完了！

⚙️ Firestore セキュリティルール設定

Firebase Consoleの「Firestore Database」>「ルール」を以下のように設定すると動作します。

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
